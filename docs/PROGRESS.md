فحوص إضافية يدوية: مخالفات مزروعة عمدًا (`any`، `console`، رقم سحري، استيراد React في `domain`، hook شرطي) التقطها lint كلها؛ تشغيل الخادم بلا `DATABASE_URL` انتهى برمز 1 ورسالة تسمّي المتغير؛ لقطة فعلية للصفحة العربية عند 390 راجعتها بالنظر.

## مراجعة مستقلة للمرحلة 1 ✅ (2026-11-24)

مراجع لم يكتب الكود. لا عيوب حرجة ولا عالية؛ سبع ملاحظات متوسطة ومنخفضة أُصلحت كلها باختبارات:

| الملاحظة                                                    | الإصلاح                                                       |
| ----------------------------------------------------------- | ------------------------------------------------------------- |
| السجل قد يكتب رسائل Prisma (تحمل قيم الاستعلام، كجوال عميل) | من أخطاء Prisma يُسجَّل النوع والرمز فقط؛ السجل لا يرمي أبدًا |
| معالج الأخطاء يبتلع `redirect()` و`notFound()`              | `unstable_rethrow` أولًا                                      |
| `money()` لا يتحقق من العملة، ويمكن بناء مبلغ بكائن حرفي    | فحص العملة، نوع مميَّز (brand)، توحيد الصفر السالب            |
| رقم منسوخ من واتساب بعلامات اتجاه غير مرئية يُرفض           | تُزال قبل الفحص، وتُقبل النقاط                                |
| `+0512…` يُقبل كرقم دولي                                    | `+` يشترط رمز الدولة بعده                                     |
| مسار فيه نقطة يفلت من ترويسة منع الفهرسة                    | الاستثناء بقائمة امتدادات محددة                               |
| `ftp://localhost` يمر من شرط https                          | البروتوكول http(s) فقط                                        |

بنود «غير متحقق منها» في التقرير فُحصت: لا تحويل مفتوح (اختبار متصفح)، البناء بلا إعداد ينجح، ونقطة الصحة ترجع 503 خلال 0.2 ثانية عند تعذر القاعدة.
