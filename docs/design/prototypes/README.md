# نماذج الاتجاهات

نماذج ثابتة معزولة للمقارنة بين الاتجاهات، **ليست كود إنتاج**: لا تُستورد من التطبيق ولا تُنشر.
الاتجاه «أ. المضمار» هو التطبيق نفسه (`apps/web`). هنا الاتجاهان الآخران بالمحتوى نفسه والأسعار التجريبية نفسها.

- `b-water.html` — «الماء»
- `c-precision.html` — «الدقة»

مواضع الصور مساحات معلَّمة «صورة مطلوبة» تصف اللقطة: لا صور مخزون ولا صور مولَّدة.
تُفتح مباشرة في المتصفح. المقارنة والاختيار في `../DIRECTION_SELECTION.md`.
