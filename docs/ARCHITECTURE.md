# المعمارية

الحالة: المرحلة 1 منفَّذة. ما تحت «مخطط» لم يُبنَ بعد. القرارات ومبرراتها في `DECISIONS.md`.

## الصورة العامة

```
 Snapchat / Instagram / Google / Search
                 │
        ┌────────▼──────────────────────────────────────┐
        │ apps/web — Next.js (عملية Node واحدة)          │
        │  صفحات مُخدَّمة من الخادم  │  واجهات /api      │
        │  src/server: env, db, http, logger            │
        └───┬───────────────┬───────────────────────────┘
            │               │ يستورد
   ┌────────▼─────┐  ┌──────▼──────────┐
   │ packages/db  │  │ packages/domain │  بلا إطار ولا قاعدة
   │ Prisma + PG  │  │ قواعد العمل     │
   └──────┬───────┘  └─────────────────┘
          │
   ┌──────▼─────┐   مخطط: عملية مهام (pg-boss) للمطابقة وإعادة المحاولة،
   │ PostgreSQL │   مزوّدو الدفع، أحداث موقّعة إلى الـCRM، دفترة للفواتير
   └────────────┘
```

## الحدود (يفرضها lint لا الاتفاق)

| الطبقة                | تستورد من        | ممنوع عليها                                           |
| --------------------- | ---------------- | ----------------------------------------------------- |
| `packages/domain`     | لا شيء           | Next، React، قاعدة البيانات (`no-restricted-imports`) |
| `packages/db`         | Prisma           | منطق عمل                                              |
| `apps/web/src/server` | `domain`، `db`   | أن يُستورد من مكوّن عميل (`server-only`)              |
| `apps/web/src/app`    | `server`، `i18n` | SQL أو حساب سعر                                       |

الحزم الداخلية تُصدَّر كمصدر TypeScript ويترجمها Next (`transpilePackages`)، فلا خطوة بناء لها.

## مسار الطلب

1. قواعد `next.config.ts`: الترويسات الأمنية، تحويل `/ar/...` إلى الرابط بلا بادئة، ثم إعادة كتابة كل مسار بلا لغة إلى `/ar/...` داخليًا.
2. `src/proxy.ts`: يضيف `X-Robots-Tag: noindex` ما لم يكن `SITE_INDEXABLE=true`.
3. `app/[locale]/layout.tsx`: يضبط `lang` و`dir`. الصفحات تُولَّد ثابتة لكل لغة.
4. الواجهات (`app/api`): تُغلَّف بـ`withErrorHandling`.

## اللغات

- العربية الأساس بلا بادئة (`/memberships`)، والإنجليزية تحت `/en`.
- القاموس العربي (`i18n/dictionaries/ar.ts`) يحدد شكل المفاتيح؛ نقص مفتاح في لغة أخرى خطأ أنواع.
- `localizedPath()` المصدر الوحيد لبناء الروابط بين اللغات.

## الأخطاء

- خطأ عمل متوقع: `DomainError` (صنف + مفتاح سبب + حقل) أو `Result` بلا رمي.
- عطل غير متوقع: استثناء عادي.
- `problemFromError` يحوّل الاثنين إلى `application/problem+json` (RFC 9457): خطأ العمل يكشف مفتاح سببه، وكل ما عداه 500 عام بلا تفاصيل مع `requestId` يُسجَّل في الخادم.
- الواجهة تترجم مفتاح السبب من القاموس؛ الخادم لا يرسل نصًا حرًا.

## الإعداد

`parseEnv` يتحقق من متغيرات البيئة عند إقلاع الخادم (`src/instrumentation.ts`): إعداد خاطئ أو ناقص يمنع الإقلاع. البناء نفسه لا يحتاج أسرارًا. رسالة الرفض تذكر اسم المتغير لا قيمته. المتغيرات في `.env.example`.

## السجلات

`logger`: سطر JSON لكل حدث باسم ثابت. ممنوع تسجيل أسرار أو بيانات بطاقات أو جوال كامل.
